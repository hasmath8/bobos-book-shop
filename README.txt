BOBO'S BOOK SALES APP

Book:
Bobo's First Little Learning Adventure
Price: LKR 450

HOW TO RUN:
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html.
4. Right-click index.html and choose "Open with Live Server" if you have Live Server installed.
   OR simply double-click index.html to open it in your browser.

CURRENT VERSION:
- Product page
- Add to cart
- Cart count
- Remove from cart
- Local browser cart storage
- Mobile responsive design

NEXT VERSION CAN ADD:
- Real book cover image
- Your shop name/logo
- Customer checkout form
- WhatsApp order button
- Bank transfer details
- Admin panel
- Database
- Multiple books

REAL BOOK COVER:
The uploaded Bobo's First Little Learning Adventure cover is included as book-cover.jpg.

FINAL FEATURES:
- Customer name, phone and delivery address form
- Cash on Delivery / Bank Transfer selection
- Orders are saved in the browser
- WhatsApp order message opens automatically
- No seller WhatsApp number is hard-coded; WhatsApp opens with the order text so the customer can choose the chat/contact.

ADMIN PAGE:
Open admin.html from the same folder.
It shows saved orders, total sales, customer details and order status.
Orders are stored in this browser's localStorage.
This is a demo/local admin panel, not a secure production login system.
